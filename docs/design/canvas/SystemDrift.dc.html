Finding 03 · Critical · The root cause
The system exists.
Nothing uses it.
Seventy-five design tokens and a set of correctly-built primitives sit in the repo, well made and largely unimported. Everything below follows from that — including the sign-in screen and the contrast failures, which are symptoms, not separate problems.

Why this is the finding that matters
Fixing the sign-in screen, the four failing button states and the position chips takes about a day. It also fixes nothing structurally: with 4,127 inline style objects and a primitive layer nobody imports, the next screen anyone builds will drift the same way, because hand-writing styles is currently the path of least resistance and the system is the detour.
What actually reverses it
Make the system cheaper than the workaround. Ban raw hex, raw pixel type and rgba(255,255,255,…) in src/ with a lint rule so the residue can't grow back; then convert screens to the primitives as they're touched rather than in one sweep. The tokens and components to convert to already exist — that work is done.
