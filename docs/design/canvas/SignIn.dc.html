What changed, and why
1
Invisible field boundary
A white-alpha fill and border on a white card. Replaced with a solid #9A9488 rule at 3.0:1 — the WCAG floor for a UI boundary — and the radius pulled from 4px to the system's 6px.
2
No visible focus state
The field sets outline: none with nothing in its place, so keyboard users lose their position entirely. Restored as a 2px accent border, shown here on the password field.
3
Labels break the type system
Field labels and tabs are set in Archivo Black at 9px. The system reserves that face for display and specifies JetBrains Mono for eyebrows — so the one screen everyone sees doesn't follow the rules the rest of the app was built on.
4
Targets under 44px
Measured live: the tab strip is 38.5px on desktop and the reset link 36px. Both raised to 44px, which also gives the tabs room to breathe.
