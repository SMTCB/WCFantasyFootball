The eight habits behind "dated"

Every screen shows some mix of these. Fixing them once, in shared components, fixes them everywhere.

01Tiny tracked typewriter labels

Section titles, tabs, buttons and metadata are set in 9–11px mono capitals with wide spacing. They read as a 2015 "tactical" aesthetic and are hard to scan.

Fix: sentence-case labels in Archivo at 13–14px. Mono is kept only for numbers, timers and codes.

02Stacked chrome before content

The league screen has 5 bands (switcher, sport nav, slab, window bar, tabs), about 350px, before the first standing. Squad and Market have 4.

Fix: one compact header plus one tab row (the Direction 2 pattern) on every competition screen.

03Two navigation layers that look alike

The sport row (Live / Squad / Market / Digest) and the league tabs use the same style, so it's unclear which level you're on. F1 and Tennis repeat it with their own sets.

Fix: a single tab row per competition. Digest moves to the clubhouse.

04"← Back" on top-level screens

Home, Squad, Market, Live, Trophy, Bets and Coins all show a Back link even though they're top-level destinations reached from the bottom bar.

Fix: Back appears only on genuinely nested pages (a player, a tournament, settings).

05Emoji as icons

370 emoji serve as UI icons: 🏠 in the switcher, ⚔️ on H2H, 🏁 for F1, ⚙ for Admin. They look different on iOS, Android and Windows and clash with the line icons in UiIcons.jsx.

Fix: one SVG line-icon set. Emoji only inside user content (chat, bets).

06Colour without a rule

Blue, navy, red, green and gold all act as "primary" somewhere. F1's buttons are red, Tennis's are blue, and the join button is pale blue.

Fix: blue is the only action colour. Sport colours become small markers, and gold is reserved for rank and trophies.

07Tables that hide the story

Standings show only a total, with placeholder "C · —" and empty form dots on mobile. The leader appears three times, and rows aren't clickable.

Fix: a shared standings row with GW points, movement and gap. Your row is highlighted, and tapping a row opens that squad (with a Compare button).

08Rough empty and error states

Raw messages like "FAILED TO LOAD: permission denied for function…", "No leagues" in grey mono, and empty skeleton rows that never resolve.

Fix: a shared empty state (icon, one sentence, one action) and a friendly error with a retry.

The target: six templates

Every screen lands on one of these. The template sets the header, spacing and navigation, and screens differ only in their content.

ACompetition page

The Direction 2 header: switcher, crest and name, meta chips, your position, one tab row, and an optional status bar (window open, race lock, draw). Used for the football league, F1 paddock and tennis box, so all three sports feel like one product.

BHub page

A light header with a title, one line of context and at most one primary action, then cards. Used by Home, Clubhouse, Trophy, Bets, Coins and Digest. No slabs.

CDetail page

Back, title and content. Used for a player, a fixture, a tournament, F1 race picks and settings.

DFocus flow

A full-screen stepper with progress, one decision per step and a sticky action. Used for sign-in, onboarding, new competition, draft, wishlist and draft recovery.

EAdmin console

A dense, utilitarian layout with grouped settings and clear destructive zones. Used for the commissioner panel and the F1, tennis and seed admin screens. Lower priority, since only admins see it.

FSheets & modals

A bottom sheet on mobile and a centred dialog on desktop, with one shell. Used for H2H, player picker, confirmations, scoring info and invites.

Shared building blocks (wave 0)

Type

  • Title 28 / Heading 20 / Body 15–16 / Label 13–14
  • 12px is the floor, for metadata only
  • Sentence case everywhere; capitals only for codes
  • Mono only for numbers, timers and invite codes

Colour

  • Blue = action and selection
  • Gold = rank, trophies, leader
  • Green / red = up/down, open/closed, live
  • Sport colour = 4px marker or crest only

Shape & space

  • Cards: white, 1px rule, 12px radius
  • Controls: 8px radius, 44px tall touch targets
  • 8-pt spacing scale; 16px mobile gutter

Components

  • PageHeader (A/B/C variants), Tabs, StatusBar
  • StandingsRow, StatPill, Card, EmptyState, ErrorState
  • Button (primary / secondary / ghost / danger), IconButton
  • Icon set replacing emoji

Rollout in waves

Each wave ships on its own, so the app is never half-styled in a confusing way. Within a wave, the screens a user moves between change together.

Wave 0Foundation
Shared tokens, the type scale, the icon set and the components listed above. Nothing visible changes yet; this is what makes everything after it fast and consistent.
Wave 1Football league
Template A on the league: Standings (Direction 2), then Squad, Market and Live as tabs of the same header, then Recap (with Market Report), Bets (merged), Stats, H2H and Trading.
  • This is where users spend most of their time, so it's the biggest visible win.
Wave 2Hubs & shell
The global top bar and bottom nav (sentence case, SVG icons, no Back on top-level screens), then Home, Clubhouse with its Frontrow front page and Digest, Trophy, Bets, Coins, Challenges and Settings.
Wave 3F1 & Tennis
Paddock and Player Box move onto Template A, with race picks, season bets, standings, report, tournaments and finals. Red and green buttons become the shared blue; sport colour stays as an accent marker.
Wave 4Flows
Template D for sign-in, onboarding, new competition, draft, wishlist and recovery. This also moves the Tailwind screens onto the shared components.
Wave 5Admin
Template E for the commissioner panel (3,265 lines, the biggest single file) and the F1, tennis and seed admin screens. Admin-only, so it goes last.

Decisions I need before the mockups

Each has a recommendation. Once these are settled, the next step is a mockup of each template applied to a real screen, so you see the full redesign before anything is built.

1 · Desktop navigation

Today desktop shows the mobile bottom bar (Home / Club / Trophy / Bets / Coins) stretched wide.

Recommend: a slim top bar on desktop (logo, those 5 destinations, clubhouse switcher, notifications, profile), with the bottom bar kept on mobile.

2 · Dark heroes or light headers

Navy and blue slabs are the most "dated" element but also the most branded one.

Recommend: light headers everywhere (as in Direction 2), with navy kept for one hero moment only: the Frontrow front page and the trophy profile.

3 · How loud the sport colours are

F1 red buttons and tabs, tennis green edges, football blue slab.

Recommend: sport colour only on the crest and a small marker. All buttons and tabs use the shared blue.

4 · Dark mode

The tokens partly support it, but no screen has been checked in dark mode.

Recommend: design for it in wave 0 (it's cheap at the token level) and switch it on after wave 2.

5 · Brand character

Dropping the mono capitals removes much of the current "editorial / tactical" voice.

Recommend: keep the voice through Archivo Black titles, the Frontrow newspaper and tabular numbers. Mono survives for scores, prices and countdowns.
